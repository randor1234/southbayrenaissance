# Photos

Images for the Photos section of southbayrenaissance.com.

- `photos/*.jpg` — the full-size images shown in the lightbox (1200 to 1600px on the long side is plenty).
- `photos/thumbs/*.jpg` — optional smaller copies (about 900px) used in the grid. Same file name as the full image. If a thumb is missing the grid falls back to the full image.
- `photos/photos.js` — the list of gatherings and their photos, newest gathering first. Adding a photo is one line there.

The hero photo at the top of the site is `2026-08-28-first-gathering-01.jpg`, referenced directly from `index.html`.
